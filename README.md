## 📋 Descripción

**Yumi** es un bot de Discord multifuncional que ofrece:

- ✅ Moderación automática del servidor  
- 🎮 Minijuegos interactivos para la comunidad  
- 🛠️ Herramientas de administración avanzadas  
- 📊 Sistema de logs configurable  
- ⚡ Comandos de utilidad para usuarios y moderadores  

---

## 🚀 Instalación

1. Invita a **Yumi Bot** a tu servidor.  
2. Configura los permisos básicos.  
3. Establece los canales de logs.  
4. Prueba los comandos iniciales.  

---

## 🎯 Comandos principales

### Moderación
- `/ban` — Banear usuarios  
- `/kick` — Expulsar usuarios  
- `/mute` — Silenciar temporalmente  
- `/warn` — Advertencias  

### Utilidad
- `/config` — Configurar el servidor  
- `/logs` — Sistema de logs  
- `/autoroles` — Roles automáticos  
- `/tickets` — Sistema de tickets  

### Entretenimiento
- `/minijuegos` — Juegos interactivos  
- `/avatar` — Visualización de avatares  
- `/svinfo` — Información del servidor
