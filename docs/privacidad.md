# 🔒 Política de Privacidad - Yumi Bot

## 2.1 Información Recopilada
**Datos del Servidor:**  
- ID del servidor y nombre  
- Configuraciones y preferencias  
- Roles y permisos configurados  
- Canales de logs y anuncios  

**Datos de Usuario:**  
- ID de usuario de Discord  
- Nombre de usuario y avatar  
- Roles y permisos en el servidor  
- Actividad y uso de comandos  

**Datos de Interacción:**  
- Comandos ejecutados  
- Configuraciones personalizadas  
- Preferencias de usuario  
- Historial de moderación  

---

## 2.2 Uso de la Información
**Propósitos principales:**  
✅ Funcionamiento del bot  
✅ Personalización de experiencia  
✅ Moderación automática  
✅ Análisis de uso y mejoras  
✅ Soporte técnico  

**NO se usa para:**  
❌ Venta a terceros  
❌ Publicidad no solicitada  
❌ Identificación personal  
❌ Seguimiento fuera de Discord  

---

## 2.3 Almacenamiento y Seguridad
**Ubicación de datos:**  
- Servidores seguros de Discord  
- Base de datos SQLite local  
- Respaldo automático de datos  
- Encriptación en tránsito  

**Medidas de seguridad:**  
- Acceso restringido al desarrollador  
- Auditoría regular de accesos  
- Monitoreo de actividades sospechosas  
- Actualizaciones de seguridad  

---

## 2.4 Compartir Información
**NO se comparte:**  
- Datos personales de usuarios  
- Información del servidor  
- Configuraciones privadas  
- Historial de actividad  

**Se puede compartir:**  
- Estadísticas anónimas agregadas  
- Información de uso general  
- Reportes de bugs (sin datos personales)  
- Mejoras del servicio  

---

## 2.5 Retención de Datos
**Períodos de retención:**  
- Datos activos: Mientras el bot esté en el servidor  
- Configuraciones: Hasta que se eliminen manualmente  
- Logs de moderación: 90 días por defecto  
- Datos de usuario: Hasta que el usuario salga del servidor  

**Eliminación automática:**  
- Datos de servidores inactivos  
- Logs antiguos de moderación  
- Configuraciones obsoletas  
- Respaldo de datos expirados  

---

## 2.6 Derechos del Usuario
**Acceso a datos:**  
- Solicitar información almacenada  
- Ver configuraciones personales  
- Revisar historial de actividad  
- Exportar datos personales  

**Control de datos:**  
- Eliminar datos personales  
- Actualizar configuraciones  
- Desactivar funcionalidades  
- Solicitar anonimización  

---

## 2.7 Cookies y Tecnologías
**No se utilizan:**  
- Cookies de seguimiento  
- Tecnologías de fingerprinting  
- Scripts de análisis externos  
- Herramientas de marketing  

**Se utilizan:**  
- Sesiones de Discord API  
- Tokens de autenticación  
- Almacenamiento local del bot  
- Logs de sistema  

---

## 2.8 Transferencias Internacionales
- **Ubicación principal:** Servidores de Discord  
- **Cumplimiento:** GDPR y regulaciones locales  
- **Transferencias:** Solo cuando sea necesario  
- **Protecciones:** Acuerdos de protección de datos  

---

## 2.9 Menores de Edad
- **Edad mínima:** 13 años (requisito de Discord)  
- **Consentimiento:** Requerido para uso  
- **Supervisión:** Recomendada para menores  
- **Protección:** Datos tratados con cuidado especial
