# 📘 Guía de Usuario - Yumi Bot

## 4.1 Primeros Pasos
**Configuración inicial:**  
1. Invitar el bot a tu servidor  
2. Configurar permisos básicos  
3. Establecer canales de logs  
4. Probar comandos básicos  
5. Personalizar configuraciones  

**Comandos esenciales:**  
- `/help` — Ver todos los comandos disponibles  
- `/config` — Configurar el servidor  
- `/infyumi` — Información del bot  
- `/invite` — Invitar el bot a otros servidores  

---

## 4.2 Moderación Básica
**Comandos de moderación:**  
- Banear usuario: `/ban @usuario [razón]`  
- Expulsar usuario: `/kick @usuario [razón]`  
- Silenciar usuario: `/mute @usuario [duración] [razón]`  
- Limpiar mensajes: `/clear [cantidad] [--verbose]`  

**Configuración de logs:**  
- Activar logs: `/config logs true #canal`  
- Seleccionar eventos: Usar menús de selección  
- Ver configuración: Botón **"Ver Configuración Actual"**  

---

## 4.3 Funcionalidades Avanzadas
**Sistema de tickets:**  
- Crear panel: `/panel tickets`  
- Configurar categorías: Personalizar tipos de tickets  
- Gestionar permisos: Control de acceso a tickets  

**Sistema de autoroles:**  
- Configurar: `/autoroles`  
- Activar/desactivar: Botones de toggle  
- Seleccionar roles: Menús de selección  

**Minijuegos:**  
- Acceder: `/minijuegos`  
- Juegos disponibles: Poker, Blackjack, PPT, etc.  
- Configuración: Personalizar juegos por servidor  

---

## 4.4 Configuración Personalizada
**Embeds personalizados:**  
- Crear embed: `/configembed [opciones]`  
- Personalizar: Título, descripción, color, imagen  
- Añadir botones: Enlaces y acciones  

**Configuración del servidor:**  
- Logs: Eventos específicos a registrar  
- Canales: Configuración de canales especiales  
- Roles: Gestión automática de roles  
- Moderación: Configuración de sistemas automáticos
