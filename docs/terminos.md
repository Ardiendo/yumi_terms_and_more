## 1.3 Descripción del Servicio
Yumi es un bot de Discord que proporciona:  
- ✅ Moderación automática del servidor  
- 🎮 Minijuegos interactivos para la comunidad  
- 🛠️ Herramientas de administración avanzadas  
- 📊 Sistema de logs configurable  
- ⚡ Comandos de utilidad para usuarios y moderadores  

---

## 1.4 Requisitos del Servicio
- **Discord:** Servidor activo con permisos adecuados  
- **Permisos del Bot:** Roles y permisos necesarios configurados  
- **Conexión a Internet:** Estable y confiable  
- **Versión de Discord:** Compatible con la versión actual  

---

## 1.5 Uso Aceptable
**✅ Permitido:**  
- Uso para moderación legítima del servidor  
- Comandos de entretenimiento y utilidad  
- Configuración de logs y sistemas automáticos  
- Uso personal y comunitario  

**❌ Prohibido:**  
- Uso malicioso o abusivo del bot  
- Spam de comandos o spam automático  
- Evasión de sistemas de moderación  
- Uso para actividades ilegales o dañinas  
- Manipulación de datos del bot  

---

## 1.6 Limitaciones del Servicio
- **Disponibilidad:** 99.5% de uptime objetivo  
- **Comandos:** Límites de rate limiting de Discord  
- **Almacenamiento:** Datos limitados por servidor  
- **Funcionalidades:** Sujetas a cambios y actualizaciones
